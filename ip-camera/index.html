Phone IP Camera

Превращает камеру Android в видеопоток для локального видеорегистратора.

Ожидание запуска

Разрешите доступ к камере. Для стабильной работы держите телефон на зарядке.

Телефон, компьютер и регистратор должны находиться в одной локальной сети. Если приложение открыто с GitHub Pages, укажите адрес компьютера в поле выше.

Параметры видеопотока

H.264 · 1280×720 · 15 кадров/с · без звука

ONVIF-служба и RTSP работают на компьютере. PWA только передаёт изображение с камеры.
